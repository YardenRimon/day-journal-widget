# יומן יום — גרסה ראשונה לאנדרואיד

אפליקציה מקומית עם ווידג׳ט למסך הבית. הווידג׳ט מציג את הרוטינות שהמשתמש מגדיר ומאפשר לסמן אותן. כפתור "סיכום ערב" פותח מסך קצר שבו אפשר להשלים סימונים, לכתוב סיכום, לקבוע עד שלוש משימות למחר ולרשום שעת השכמה. שעת ההשכמה נשמרת בלבד; אין התראה או שעון מעורר.

המאגר הציבורי כולל קוד והגדרות בנייה בלבד. הוא אינו כולל משימות, רוטינות או רישומי יומן אישיים. רוטינות ומשימות מתחילות ריקות ונשמרות במסד הנתונים של האפליקציה במכשיר.

## כללי היום

- היום הפעיל מתחלף ב־02:00 לפי השעון המקומי של המכשיר. לדוגמה, סימון ביום שלישי ב־01:30 עדיין שייך ליום שני.
- אין איפוס או מחיקה של יום קודם. לכל יום נשמרים סיכום, רוטינות, משימות ושעת ההשכמה שתוכננה עבורו.
- ההתקנה מתחילה ללא רוטינות או משימות. כל משתמש מוסיף את הרוטינות שלו מתוך האפליקציה.
- רוטינות אפשר להוסיף, לשנות שם, לשנות סדר, להסיר ולהחזיר. היסטוריית הימים הקודמים שומרת את השמות והסימונים שלה.
- היומן מציג את כל התאריכים מהשימוש הראשון עד היום, כולל ימים ללא רישום. פתיחת יום שלא נפתח בעבר יוצרת בו את רשימת הרוטינות הפעילה באותו רגע, ללא סימונים; ימים שכבר נפתחו שומרים את הרשימה והשמות שלהם. אפשר לערוך סיכום, משימות, שעת השכמה וסימונים.
- משימות אינן עוברות ליום הבא אוטומטית. את המשימות למחר קובעים במסך הערב.

## פתיחה ובנייה

1. פתח את התיקייה הזו כפרויקט ב־Android Studio.
2. ודא שמותקנים JDK 17 ו־Android SDK 36. בפרויקט כלול Gradle Wrapper 8.13.
3. בצע Gradle Sync, בנה את `app` והרץ על מכשיר Android 8.0 ומעלה.
4. הוסף רוטינות מתוך האפליקציה. לאחר מכן לחץ לחיצה ארוכה במסך הבית, הוסף את הווידג׳ט "יומן יום" ובחר לו מקום מספיק גבוה לרשימה שלך.

הפרויקט משתמש ב־Kotlin, Jetpack Compose, Glance ו־Room. הנתונים נשמרים במסד מקומי. הגדרת הגיבוי של Android מופעלת דרך `allowBackup`, בהתאם להגדרות הגיבוי במכשיר.

## מצב האימות

קובצי ה־XML נבדקו לתקינות מבנית והפרויקט כולל את קובצי Gradle Wrapper. בדיקת בנייה אוטומטית ב־GitHub Actions מוגדרת בקובץ `.github/workflows/android.yml`; תוצאת הבנייה תופיע בלשונית Actions. עדיין נדרשת בדיקה על מכשיר לפני שימוש יומי.

הווידג׳ט מבקש רענון מחזורי כל 30 דקות וגם מתרענן אחרי אינטראקציה. Android קובע מתי לרנדר רענונים מחזוריים בפועל, ולכן המעבר החזותי על מסך הבית סביב 02:00 עשוי להתעכב; כל סימון לאחר 02:00 יישמר ביום הנכון.
